# Football ELT Pipeline ⚽

An automated, end-to-end data pipeline designed to ingest, clean and model highly volatile football API data. Built on PostgreSQL dbt, and Airflow, this system enforces strict data quality checks, handles source API rate limits, and guarantees daily freshness for downstream analytics.
